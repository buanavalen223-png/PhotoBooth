# MOCHI BOOTH 📸
> *“Little moments, forever memories.”*

Modern Korean Self-Photo Booth web application built with **React 18, TypeScript, Vite, HTML5 Canvas, IndexedDB, and MediaPipe Face Landmarker**.

## ✨ Key Features
- **Live AR Face Filters (51 Filters + 10 Camera Color Tones):** Real-time 478-point 3D face tracking powered by `@mediapipe/tasks-vision` (Animal Ears, Wigs/Hair, Cute Accessories, Blush/Makeup, Fantasy Sparkles, and Seasonal Hats).
- **Multi-Effect Combination:** Combine compatible AR effects simultaneously (e.g., *Bunny Ears* + *Heart Glasses* + *Rosy Pink Cheeks* + *Floating Hearts*).
- **10 Studio Layouts:** Classic Korean 4-Cut Strip, Mini 3-Cut Strip, Double Twin Strip (8 shots), Square Collage, Grid 2×2, Grid 2×3, Grid 3×2, Single Portrait, Polaroid Style, and Scrapbook Free Collage.
- **16 Cute Frame Themes:** Custom vector patterns, pastel palettes, customizable spacing, border thickness, corner roundness, and date stamps.
- **Full Photo Editor:** 13 filters, brightness/contrast/saturation/zoom/crop-pan sliders, 90° rotation, horizontal flip, 16 draggable vector stickers, custom text overlays, and Undo/Redo history.
- **High-Res Export & Local Gallery:** Download crisp 1×, 1.5×, or 2× PNG/JPEG strips, print directly, or save to your private browser IndexedDB gallery.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run unit tests
npm run test

# Build for production
npm run build
```
